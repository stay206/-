# Bangumi 保管库 v0.31.1

本版本新增 GitHub 云端同步通道，修复设置面板布局重叠，并移除自建代理部署说明。

## 更新内容

- 顶部工具栏新增「同步到云端」按钮，可一键把本地资料库提交并推送到 GitHub 仓库「资料库」分支的 `vault/state.json`。
- 新增独立「云端同步（GitHub 仓库）」弹窗，支持填写 GitHub Token、仓库名、分支名，并提供「保存设置 / 从云端恢复 / 同步到云端」三个动作。
- 新设备首次打开、本地资料库为空且已配置 GitHub 信息时，自动从云端分支恢复数据。
- 将内嵌的云端同步面板从设置网格中拆出为独立弹窗，彻底解决与「高级网络设置」在部分分辨率/主题下文字重叠的问题。
- 补全云端同步按钮的事件绑定，避免点击无反应。
- 移除 README 中的「自建代理」部署说明；在线版仍保留高级网络设置中的自定义 API / 图片反代 / 站点镜像能力。
