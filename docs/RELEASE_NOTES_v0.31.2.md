# Bangumi 保管库 v0.31.2

本版本将云端同步整合进账号与同步面板，并完善 GitHub Token 获取引导。

## 更新内容

- 云端同步（GitHub 仓库）合并入「账号与同步」面板，不再单独成卡，设置更集中。
- 原 Access Token 字段改名为「Bangumi Access Token」，与下方的 GitHub Personal Access Token 明确区分。
- GitHub Personal Access Token 新增「获取 Token」按钮，点击一键跳转 GitHub 创建页，并预填 repo 权限和描述。
- 精简 GitHub Token 获取说明，改为按钮跳转式引导，降低上手成本。
